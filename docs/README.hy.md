**DeckyWolf**-ը **LibreWolf** բրաուզերի օպտիմիզացված տարբերակն է, որը ստեղծված է հատուկ **Steam Deck** կոնսոլի համար:

### Հիմնական առանձնահատկությունները
- 🎮 **Ամբողջական կառավարում գեյմպադով**: Ստիկեր, խաչուկ (D-pad), գործողությունների կոճակներ, տրիգերներ և հետևի թևիկներ (L4, L5, R4, R5):
- 🔄 **Շրջանաձև ոլորում ձախ թրեքփադով և վիբրացիայով**: Էջերի ոլորում շրջանաձև շարժումով և մկնիկի միջին կոճակի սեղմում:
- 🔀 **Կառավարման ռեժիմի փոխարկիչ**: «Կոնտրոլեր» և «Ստեղնաշար + մկնիկ» ռեժիմների արագ փոփոխում:
- 💡 **Կոճակների վիզուալ հուշումներ**: Xbox, PlayStation և Steam Deck ոճի հուշումներ էկրանին:
- ⚙️ **«Կոնտրոլեր» բաժին կարգավորումներում**: `about:preferences#controller` բաժին՝ զգայունությունը և կոճակները հարմարեցնելու համար:

### Տեղադրում
Ներբեռնեք `deckywolf.AppImage` ֆայլը [Releases](https://github.com/Kowalski-coder/DeckyWolf/releases) բաժնից, տվեք գործարկման թույլտվություն և բացեք այն:
```bash
chmod +x deckywolf.AppImage
./deckywolf.AppImage
```
