**DeckyWolf**-ը **LibreWolf** բրաուզերի օպտիմիզացված տարբերակն է, որը ստեղծված է հատուկ **Steam Deck** կոնսոլի համար:

### Հիմնական հնարավորությունները
- 🎮 **Steam Deck կոնտրոլլերի և այլ գեյմպադների լիարժեք աջակցություն**՝ Ստիկներ, D-pad, գործողությունների կոճակներ, տրիգերներ և հետևի թևիկներ (L4, L5, R4, R5), էկրանային հուշումների ոճի ընտրություն (**Xbox**, **Sony / PlayStation**, **Nintendo**):
- 🔄 **Ձախ թրեքփադով պտտվող թերթում և հապտիկ հետադարձ կապ**՝ Էջերի հարմարավետ թերթում թրեքփադի պտույտով և միջին կոճակի սեղմումով:
- 🧩 **Փլագինների կառավարում deckyloader.ru կայքի միջոցով**՝ Փլագինի տարբերակի ընտրություն, տեղադրում, թարմացում և հեռացում անմիջապես [deckyloader.ru](https://deckyloader.ru) կայքից Decky Loader-ի հետ ակնթարթային սինխրոնացմամբ:
- 📥 **Ներկառուցված տորենտ-հաճախորդ (TorrentWolf)**՝ Մեկ սեղմումով տեղադրվող փլագին, որը թույլ է տալիս կառավարել ներբեռնումները անմիջապես բրաուզերից: Բրաուզերը փակելիս կամ խաղային ռեժիմ անցնելիս ներբեռնումները չեն ընդհատվում:
- 🛡️ **LibreWolf-ի բոլոր ստանդարտ գործառույթները**՝ Գովազդի արգելափակում (uBlock Origin), Firefox հավելումների աջակցություն, արագություն, գաղտնիություն և սինխրոնացում Mozilla-ի միջոցով:
- 🔀 **Կառավարման ռեժիմի անջատիչ**՝ Արագ անցում կոնտրոլլերի և մկնիկի ռեժիմների միջև:
- ⚙️ **«Կոնտրոլլեր» բաժին կարգավորումներում**՝ `about:preferences#controller` (105 լեզուների աջակցությամբ):
- 🏷️ **Ամբողջական ինքնավարություն**՝ DeckyWolf-ը գործարկվում է որպես առանձին հավելված իր պատկերակով և `app_id`-ով:

### Տեղադրում
Ներբեռնեք `deckywolf.AppImage` ֆայլը [Releases](https://github.com/Kowalski-coder/DeckyWolf/releases) բաժնից, տվեք գործարկման թույլտվություն և բացեք այն:
```bash
chmod +x deckywolf.AppImage
./deckywolf.AppImage
```
