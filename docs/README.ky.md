**DeckyWolf** — бул **Steam Deck** үчүн атайын оптималдаштырылган **LibreWolf** браузеринин чыгарылышы.

### Негизги мүмкүнчүлүктөр
- 🎮 **Steam Deck контроллерин жана башка геймпаддарды толук колдоо**: Стиктер, D-pad, аракет баскычтары, триггерлер жана арткы баскычтар (L4, L5, R4, R5), экрандагы көрсөтмөлөрдүн стилин тандоо (**Xbox**, **Sony / PlayStation**, **Nintendo**).
- 🔄 **Сол трекпад аркылуу айланма жылдыруу жана титирөө кайтарымы**: Иш такта режиминдегидей ыңгайлуу барактоо жана ортоңку баскычты басуу.
- 🧩 **deckyloader.ru сайты аркылуу плагиндерди башкаруу**: Плагиндин версиясын тандоо, орнотуу, жаңыртуу жана түздөн-түз [deckyloader.ru](https://deckyloader.ru) сайты аркылуу өчүрүү, Decky Loader менен заматта синхрондоштуруу.
- 📥 **Браузерге интеграцияланган торрент-кардар (TorrentWolf)**: Браузер аркылуу жүктөмөлөрдү башкарууга мүмкүндүк берген плагинди бир чыкылдатуу менен орнотуу. Браузерди жапканда же оюн режимине өткөндө жүктөмөлөр фондук режимде үзгүлтүксүз улана берет.
- 🛡️ **LibreWolf браузеринин бардык стандарттуу функциялары**: Жарнамаларды жана трекерлерди бөгөттөө (uBlock Origin), Firefox кеңейтүүлөрүн колдоо, ылдамдык жана купуялуулук, Mozilla аркылуу синхрондоштуруу.
- 🔀 **Башкаруу режимин которгуч**: Контроллер жана «Клавиатура+чычкан» режимдеринин ортосунда тез өтүү.
- ⚙️ **Жөндөөлөрдөгү «Контроллер» бөлүмү**: `about:preferences#controller` аркылуу ыңгайлуу конфигурация (105 тил колдоого алынат).
- 🏷️ **Толук көз карандысыздык**: DeckyWolf өз сөлөкөтү жана `app_id` менен өзүнчө тиркеме катары иштейт.

### Орнотуу
[Releases](https://github.com/Kowalski-coder/DeckyWolf/releases) бөлүмүнөн `deckywolf.AppImage` жүктөп алып, иштетүү укугун берип, ачыңыз:
```bash
chmod +x deckywolf.AppImage
./deckywolf.AppImage
```
