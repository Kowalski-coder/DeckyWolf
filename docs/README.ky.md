**DeckyWolf** — бул **Steam Deck** үчүн атайын оптималдаштырылган **LibreWolf** браузеринин чыгарылышы.

### Негизги өзгөчөлүктөрү
- 🎮 **Геймпад менен толук башкаруу**: Стиктер, D-pad, баскычтар, триггерлер жана арткы калакчалар (L4, L5, R4, R5).
- 🔄 **Сол трекпад менен тегерек сыдыруу**: Тактилдик дирилдөө менен айлантуу жана ортоңку чычкан баскычын басуу.
- 🔀 **Башкаруу режимин алмаштыргыч**: «Контроллер» жана «Клавиатура+чычкан» режимдеринин ортосунда тез өтүү.
- 💡 **Экрандагы баскыч кеңештери**: Xbox, PlayStation, Steam Deck стилиндеги так белгилер.
- ⚙️ **Орнотуулардагы «Контроллер» бөлүмү**: `about:preferences#controller` аркылуу сезгичтикти жана баскычтарды жөндөө.

### Орнотуу
[Releases](https://github.com/Kowalski-coder/DeckyWolf/releases) бөлүмүнөн `deckywolf.AppImage` жүктөп алып, иштетүү укугун берип, ачыңыз:
```bash
chmod +x deckywolf.AppImage
./deckywolf.AppImage
```
