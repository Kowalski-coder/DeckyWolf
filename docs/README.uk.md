**DeckyWolf** — це оптимізований форк браузера **LibreWolf**, створений спеціально для портативної консолі **Steam Deck** та інших портативних ПК на Linux. Браузер поєднує повноцінне керування з геймпада, кругове прокручування трекпадом з вібровідгуком, візуальні підказки кнопок та окрему панель налаштувань.

### Основні можливості
- 🎮 **Повноцінна підтримка контролера Steam Deck та сторонніх геймпадів**: Керування стіками, хрестовиною (D-pad), кнопками дій, тригерами та задніми пелюстками (L4, L5, R4, R5), з можливістю вибору стилю екранних підказок (**Xbox**, **Sony / PlayStation**, **Nintendo**).
- 🔄 **Кругове прокручування лівим трекпадом з тактильним відгуком**: Лівий трекпад працює як коліщатко прокручування в десктопному режимі Steam Deck з реалістичними клацаннями вібромотора і натисканням для СКМ.
- 🧩 **Керування плагінами через сайт deckyloader.ru**: Вибір версії плагіна, встановлення, оновлення та видалення плагінів безпосередньо через інтерфейс сайту [deckyloader.ru](https://deckyloader.ru) з миттєвою синхронізацією з Decky Loader без перезапуску Steam.
- 📥 **Інтеграція торрент-клієнта в браузер (TorrentWolf)**: В один клік встановлюється плагін, що дозволяє керувати завантаженнями просто з браузера (додавання, пауза, відновлення, видалення з файлами або без). При закритті браузера або переході в ігровий режим завантаження не перериваються, оскільки всі процеси виконує фоновий демон плагіна.
- 🛡️ **Усі стандартні функції браузера LibreWolf**: Вбудоване блокування реклами та трекерів (uBlock Origin), підтримка сторонніх розширень Firefox, акцент на швидкість і приватність, а також опціональна синхронізація через сервіси Mozilla.
- 🔀 **Перемикач режиму керування на панелі інструментів**: Зручна кнопка для швидкого перемикання між режимами «Контролер» та «Клавіатура+миша».
- ⚙️ **Вкладка «Контролер» у налаштуваннях**: Окремий розділ `about:preferences#controller` для налаштування чутливості, інверсії прокручування, вибору стилю підказок та кнопки-модифікатора (підтримка 105 мов).
- 🏷️ **Повна незалежність**: DeckyWolf запускається як окремий застосунок зі своєю іконкою, назвою та `app_id`.

### Схема керування
| Елемент керування | Звичайна дія | При затиснутому модифікаторі (L5 / L4 / R4 / R5 / View) |
| :--- | :--- | :--- |
| **Правий стік** | Переміщення курсора миші | — |
| **Лівий стік** | Вертикальне прокручування | — |
| **Лівий трекпад (обертання)** | Кругове прокручування з вібровідгуком | — |
| **Лівий трекпад (натискання)**| Середня кнопка миші (СКМ) | — |
| **R2 (Правий тригер)** | Ліва кнопка миші (ЛКМ) | — |
| **L2 (Лівий тригер)** | Права кнопка миші (ПКМ) | — |
| **R3 (Натискання правого стіка)** | Ліва кнопка миші (ЛКМ) | — |
| **L3 (Натискання лівого стіка)** | Середня кнопка миші (СКМ) | — |
| **L3 + R3 (одночасно)** | Повноекранний режим (F11) | — |
| **Хрестовина (D-Pad)** | Стрілки клавіатури | — |
| **L1 (LB)** | Попередня вкладка | — |
| **R1 (RB)** | Наступна вкладка | — |
| **Кнопка B** | Назад в історії | **Закрити поточну вкладку** |
| **Кнопка X** | Вперед в історії | — |
| **Кнопка Y** | Оновити сторінку | **Відкрити нову вкладку** |

> **Примітка для режиму робочого столу SteamOS:** Затисніть кнопку меню (**☰**) на 3 секунди, щоб перемкнути розкладку Steam на геймпад.

### Встановлення
Завантажте `deckywolf.AppImage` з розділу [Releases](https://github.com/Kowalski-coder/DeckyWolf/releases), зробіть файл виконуваним і запустіть:
```bash
chmod +x deckywolf.AppImage
./deckywolf.AppImage
```
