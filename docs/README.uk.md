**DeckyWolf** — це оптимізований форк браузера **LibreWolf**, створений спеціально для портативної консолі **Steam Deck** та інших портативних ПК на Linux. Браузер поєднує повноцінне керування з геймпада, кругове прокручування трекпадом з вібровідгуком, візуальні підказки кнопок та окрему панель налаштувань.

### Основні можливості
- 🎮 **Повноцінне керування з геймпада**: Працюють стіки, хрестовина (D-pad), кнопки дій, тригери та задні пелюстки (L4, L5, R4, R5).
- 🔄 **Кругове прокручування лівим трекпадом з тактильним відгуком**: Лівий трекпад працює точно як у десктопному режимі Steam Deck — обертання пальцем прокручує сторінку з приємними тактильними клацаннями, а натискання емулює середню кнопку миші.
- 🔀 **Перемикач режиму керування на панелі інструментів**: Зручна кнопка для швидкого перемикання між режимами «Контролер» та «Клавіатура+миша».
- 💡 **Візуальні підказки кнопок**: Наочні іконки кнопок (A, B, X, Y, L1, R1, L5) прямо на вкладках і панелі навігації (стилі Xbox, PlayStation, Steam Deck).
- ⚙️ **Вкладка «Контролер» у налаштуваннях**: Окремий розділ `about:preferences#controller` для налаштування чутливості, інверсії прокручування та вибору кнопки-модифікатора (підтримка 105 мов).
- 🛡️ **Приватність LibreWolf**: Усі захисні функції LibreWolf зі зручними налаштуваннями за замовчуванням.
- 🏷️ **Повна незалежність**: DeckyWolf запускається як окремий застосунок зі своєю іконкою, назвою та `app_id`.

### Схема керування
| Елемент керування | Звичайна дія | При затиснутому модифікаторі (L5 / L4 / R4 / R5 / View) |
| :--- | :--- | :--- |
| **Правий стік** | Переміщення курсора миші | — |
| **Лівий стік** | Вертикальне прокручування | — |
| **Лівий трекпад (обертання)** | Кругове прокручування з вібровідгуком | — |
| **Лівий трекпад (натискання)**| Середня кнопка миші (СКМ) | — |
| **R2 (Правий тригер)** | Ліва кнопка миші (ЛКМ) | — |
| **L2 (Лівий тригер)** | Права кнопка миші (ПКМ) | — |
| **R3 (Натискання правого стіка)** | Ліва кнопка миші (ЛКМ) | — |
| **L3 (Натискання лівого стіка)** | Середня кнопка миші (СКМ) | — |
| **L3 + R3 (одночасно)** | Повноекранний режим (F11) | — |
| **Хрестовина (D-Pad)** | Стрілки клавіатури | — |
| **L1 (LB)** | Попередня вкладка | — |
| **R1 (RB)** | Наступна вкладка | — |
| **Кнопка B** | Назад в історії | **Закрити поточну вкладку** |
| **Кнопка X** | Вперед в історії | — |
| **Кнопка Y** | Оновити сторінку | **Відкрити нову вкладку** |

> **Примітка для режиму робочого столу SteamOS:** Затисніть кнопку меню (**☰**) на 3 секунди, щоб перемкнути розкладку Steam на геймпад.

### Встановлення
Завантажте `deckywolf.AppImage` з розділу [Releases](https://github.com/Kowalski-coder/DeckyWolf/releases), зробіть файл виконуваним і запустіть:
```bash
chmod +x deckywolf.AppImage
./deckywolf.AppImage
```
