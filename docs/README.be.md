**DeckyWolf** — гэта аптымізаваны форк браўзера **LibreWolf**, створаны адмыслова для партатыўнай кансолі **Steam Deck** і іншых партатыўных ПК пад кіраваннем Linux. Браўзер спалучае паўнавартаснае кіраванне з геймпада, кругавую пракрутку трэкпадам з вібрааддачай, візуальныя падказкі кнопак і асобную панэль налад.

### Асноўныя магчымасці
- 🎮 **Паўнавартаснае кіраванне з геймпада**: Працуюць сцікі, крыжавіна (D-pad), кнопкі дзеянняў, трыгеры і заднія пялёсткі (L4, L5, R4, R5).
- 🔄 **Кругавая пракрутка левым трэкпадам з тактыльнай аддачай**: Левы трэкпад працуе дакладна як у рэжыме працоўнага стала Steam Deck — кручэнне па трэкпадзе пракручвае старонку з рэалістычнымі пстрычкамі, а націск эмулюе сярэднюю кнопку мышы.
- 🔀 **Пераключальнік рэжыму кіравання на панэлі інструментаў**: Зручная кнопка для хуткага пераключэння паміж рэжымамі «Кантролер» і «Клавіятура+мыш».
- 💡 **Візуальныя падказкі кнопак**: Навочныя значкі кнопак (A, B, X, Y, L1, R1, L5) прама на ўкладках і панэлі навігацыі (стылі Xbox, PlayStation, Steam Deck).
- ⚙️ **Укладка «Кантролер» у наладах**: Асобны раздзел `about:preferences#controller` для налады адчувальнасці, інверсіі пракруткі і выбару кнопкі-мадыфікатара (падтрымка 105 моў).
- 🛡️ **Прыватнасць LibreWolf**: Усе механізмы абароны LibreWolf з аптымізаванымі параметрамі па змаўчанні.
- 🏷️ **Поўная незалежнасць**: DeckyWolf запускаецца як асобнае прыкладанне са сваім імем, значком і `app_id`.

### Схема кіравання
| Элемент кіравання | Звычайнае дзеянне | Пры заціснутым мадыфікатары (L5 / L4 / R4 / R5 / View) |
| :--- | :--- | :--- |
| **Правы сцік** | Перамяшчэнне курсора мышы | — |
| **Левы сцік** | Вертыкальная пракрутка | — |
| **Левы трэкпад (кручэнне)** | Кругавая пракрутка з вібрааддачай | — |
| **Левы трэкпад (націск)** | Сярэдняя кнопка мышы (СКМ) | — |
| **R2 (Правы трыгер)** | Левая кнопка мышы (ЛКМ) | — |
| **L2 (Левы трыгер)** | Правая кнопка мышы (ПКМ) | — |
| **R3 (Націск правага сціка)** | Левая кнопка мышы (ЛКМ) | — |
| **L3 (Націск левага сціка)** | Сярэдняя кнопка мышы (СКМ) | — |
| **L3 + R3 (разам)** | Поўнаэкранны рэжым (F11) | — |
| **Крыжавіна (D-Pad)** | Стрэлкі клавіятуры | — |
| **L1 (LB)** | Папярэдняя ўкладка | — |
| **R1 (RB)** | Наступная ўкладка | — |
| **Кнопка B** | Назад у гісторыі | **Закрыць бягучую ўкладку** |
| **Кнопка X** | Наперад у гісторыі | — |
| **Кнопка Y** | Абнавіць старонку | **Адкрыць новую ўкладку** |

> **Заўвага для SteamOS Desktop Mode:** Зацісніце кнопку меню (**☰**) на 3 секунды, каб пераключыць раскладку Steam на геймпад.

### Усталёўка
Спампуйце `deckywolf.AppImage` з раздзела [Releases](https://github.com/Kowalski-coder/DeckyWolf/releases), зрабіце файл выканальным і запусціце:
```bash
chmod +x deckywolf.AppImage
./deckywolf.AppImage
```
