**DeckyWolf** — ин нусхаи оптимизатсияшудаи браузери **LibreWolf** барои дастгоҳи **Steam Deck** мебошад.

### Хусусиятҳои асосӣ
- 🎮 **Идоракунии пурра бо геймпад**: Стикҳо, D-pad, тугмаҳо, триггерҳо ва тугмаҳои қафо (L4, L5, R4, R5).
- 🔄 **Гардиши доиравӣ бо трекпади чап ва вибро**: Саҳифагардонӣ бо вибро ва пахши тугмаи мобайнии муш.
- 🔀 **Ивазкунандаи ҳолати идоракунӣ**: Гузариши фаврӣ байни ҳолатҳои «Контроллер» ва «Клавиатура+муш».
- 💡 **Ишораҳои визуалии тугмаҳо**: Нишонаҳои услуби Xbox, PlayStation ва Steam Deck дар экран.
- ⚙️ **Бахши «Контроллер» дар танзимот**: `about:preferences#controller` барои танзими ҳассосият.

### Насбкунӣ
Файли `deckywolf.AppImage`-ро аз бахши [Releases](https://github.com/Kowalski-coder/DeckyWolf/releases) боргирӣ намуда, иҷро намоед:
```bash
chmod +x deckywolf.AppImage
./deckywolf.AppImage
```
