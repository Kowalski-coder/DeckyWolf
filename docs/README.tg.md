**DeckyWolf** — ин нусхаи оптимизатсияшудаи браузери **LibreWolf** барои дастгоҳи **Steam Deck** мебошад.

### Имкониятҳои асосӣ
- 🌐 **Мудири дохилии барномаҳои веб**: Ҳар як сайтро бо як клик аз сатри асбобҳо ба барномаи мустақили веб табдил диҳед. Интегратсияи худкор бо Steam ва менюи системавӣ.
- 🎮 **Дастгирии пурраи ҳолати бозии Steam (Game Mode бе хирагӣ)**: Кори комил дар Gamescope бе чаҳорчӯбаҳои сафед ва бо возеҳияти баланди экран (1280×800 дар Deck, 1080p/4K дар мониторҳо).
- 🎮 **Дастгирии пурраи контроллери Steam Deck ва геймпадҳои дигар**: Идоракунӣ бо стикҳо, D-pad, тугмаҳои амал, триггерҳо ва баромадҳои қафо (L4, L5, R4, R5), интихоби сабки тугмаҳои экран (**Xbox**, **Sony / PlayStation**, **Nintendo**).
- 🔄 **Гардиши чархӣ бо трекпади чап ва фикру мулоҳизаи тактилӣ**: Саҳифаҳоро бо чарх задани трекпад ва пахш кардани тугмаи миёнаи муш ба осонӣ варақ занед.
- 🧩 **Идоракунии плагинҳо тавассути сайти deckyloader.ru**: Интихоби версияи плагин, насб, навсозӣ ва нест кардани плагинҳо мустақиман тавассути интерфейси [deckyloader.ru](https://deckyloader.ru) бо ҳамоҳангсозии фаврӣ бо Decky Loader.
- 📥 **Мизоҷи торрентии воридшуда дар браузер (TorrentWolf)**: Насби плагин бо як клик барои идоракунии боргириҳо мустақиман аз браузер. Ҳангоми пӯшидани браузер ё гузаштан ба ҳолати бозӣ боргириҳо дар замина бефосила идома меёбанд.
- 🦊 **Ҳолати ҷудогонаи «Белый Лис» (сертификатҳои Минсифрӣ)**: Ҳолати ихтиёрӣ барои дастрасии бехатар ба хидматҳое, ки сертификатҳои TLS-и Минсифриро талаб мекунанд. Сертификатҳо танҳо дар дохили браузер кор карда, ба системаи SteamOS насб намешаванд. Аз сатри абзорҳо ё `about:preferences#belylis` идора карда мешавад.
- 🛡️ **Ҳама вазифаҳои стандартии LibreWolf**: Бастани таблиғот ва пайгирҳо (uBlock Origin), дастгирии васеъшавиҳои Firefox, суръат, махфият ва ҳамоҳангсозӣ тавассути Mozilla.
- 🔀 **Гузариш байни ҳолатҳои идоракунӣ**: Гузариши фаврӣ байни ҳолати контроллер ва «Клавиатура+муш».
- ⚙️ **Бахши «Контроллер» дар танзимот**: `about:preferences#controller` (бо дастгирии 105 забон).
- 🏷️ **Истиқлолияти комил**: DeckyWolf ҳамчун барномаи алоҳида бо нишона ва `app_id`-и худ кор мекунад.

### Насбкунӣ
Файли `deckywolf.AppImage`-ро аз бахши [Releases](https://github.com/Kowalski-coder/DeckyWolf/releases) боргирӣ намуда, иҷро намоед:
```bash
chmod +x deckywolf.AppImage
./deckywolf.AppImage
```
