**DeckyWolf** — бұл **Steam Deck** консолі және Linux портативті құрылғылары үшін арнайы жасалған **LibreWolf** браузерінің оңтайландырылған нұсқасы. Ол геймпадпен толық басқаруды, трекпадтағы дірілмен айналдыруды және ыңғайлы баптауларды біріктіреді.

### Негізгі мүмкіндіктер
- 🌐 **Кіріктірілген веб-қолданбалар менеджері**: Кез келген сайтты құралдар тақтасынан бір рет басу арқылы жеке веб-қолданбаға айналдырыңыз. Steam және жүйелік мәзірмен автоматты интеграция.
- 🎮 **Steam ойын режимін толық қолдау (бұлдырсыз және жақтаусыз Game Mode)**: Gamescope жүйесінде ақ жақтаусыз, автоматты ажыратымдылықпен (Декте 1280×800, мониторларда 1080p/4K) және тегіс трекпадпен тамаша жұмыс істейді.
- 🎮 **Steam Deck контроллері мен басқа геймпадтарды толық қолдау**: Стиктер, D-pad, әрекет түймелері, триггерлер және артқы батырмалар (L4, L5, R4, R5), экрандық кеңес мәнерлерін таңдау мүмкіндігі (**Xbox**, **Sony / PlayStation**, **Nintendo**).
- 🔄 **Сол жақ трекпадпен айналмалы айналдыру және тактильді кері байланыс**: Трекпад жұмыс үстелі режиміндегідей шынайы вибро шертулермен және ортаңғы тышқан батырмасымен жұмыс істейді.
- 🧩 **deckyloader.ru сайты арқылы плагиндерді басқару**: Плагин нұсқасын таңдау, орнату, жаңарту және [deckyloader.ru](https://deckyloader.ru) интерфейсі арқылы тікелей өшіру, Steam қайта іске қоспай-ақ Decky Loader-мен лезде синхрондау.
- 📥 **Браузерге кіріктірілген торрент-клиент (TorrentWolf)**: Браузер арқылы жүктеулерді басқаруға, торренттерді қосуға, кідіртуге және өшіруге мүмкіндік беретін плагинді бір шертумен орнату. Браузерді жапқанда немесе ойын режиміне өткенде де жүктеу фондық демоны арқылы үзілмейді.
- 🦊 **Оқшауланған «Белый Лис» режимі (Минцифры сертификаттары)**: Ресейлік цифрлық даму министрлігінің TLS сертификаттарын талап ететін сервистерге қауіпсіз кіруге арналған қосымша режим. Сертификаттар тек браузер ішінде жұмыс істейді және ешқашан SteamOS жүйесіне орнатылмайды. Құралдар тақтасындағы түйме арқылы немесе `about:preferences#belylis` баптауларында бір басумен қосылады және өшіріледі.
- 🛡️ **LibreWolf-тің барлық стандартты мүмкіндіктері**: Кіріктірілген жарнама мен трекерлерді бұғаттау (uBlock Origin), Firefox кеңейтімдерін қолдау, жылдамдық пен құпиялылық, Mozilla арқылы деректерді міндетті емес синхрондау.
- 🔀 **Құралдар тақтасындағы басқару режимін ауыстырғыш**: Контроллер және «Пернетақта+тышқан» режимдері арасында жылдам ауысу.
- ⚙️ **Баптаулардағы «Контроллер» қойындысы**: `about:preferences#controller` бөлімі (105 тілде қолжетімді).
- 🏷️ **Толық дербестік**: DeckyWolf жеке қолданба ретінде өз белгішесімен және `app_id` жұмыс істейді.

### Басқару кестесі
| Басқару құралы | Әдеттегі әрекет | Модификатор басулы кезде (L5 / L4 / R4 / R5 / View) |
| :--- | :--- | :--- |
| **Оң жақ стик** | Тінтуір меңзерін жылжыту | — |
| **Сол жақ стик** | Тігінен айналдыру | — |
| **Сол трекпад (айналдыру)** | Тактильді дірілмен айналдыру | — |
| **Сол трекпад (басу)** | Тінтуірдің ортаңғы батырмасы | — |
| **R2 (Оң триггер)** | Сол жақ тінтуір батырмасы (ЛКМ) | — |
| **L2 (Сол триггер)** | Оң жақ тінтуір батырмасы (ПКМ) | — |
| **R3 (Оң стикті басу)** | Сол жақ тінтуір батырмасы | — |
| **L3 (Сол стикті басу)** | Ортаңғы тінтуір батырмасы | — |
| **L3 + R3 (бірге)** | Толық экран режимі (F11) | — |
| **Крестовина (D-Pad)** | Бағыттауыш пернелер | — |
| **L1 (LB)** | Алдыңғы қойынды | — |
| **R1 (RB)** | Келесі қойынды | — |
| **B батырмасы** | Тарихта артқа | **Ағымдағы қойындыны жабу** |
| **X батырмасы** | Тарихта алға | — |
| **Y батырмасы** | Бетті жаңарту | **Жаңа қойынды ашу** |

> **Кеңес:** SteamOS жұмыс үстелі режимінде Steam геймпад режиміне ауысуы үшін мәзір батырмасын (**☰**) 3 секунд ұстап тұрыңыз.
