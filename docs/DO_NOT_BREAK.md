# DeckyWolf: Архитектурные ограничения и правила «ЧТО НЕЛЬЗЯ ЛОМАТЬ»

> ⛔ **КРИТИЧЕСКИ ВАЖНО**: При каждом обновлении движка LibreWolf/Firefox этот документ является обязательным стандартом. Нарушение этих правил приводит к регрессиям интерфейса (пропадание меню, артефакты кнопок, слетевшие иконки).

---

## 1. Золотое правило: Никакого слепого перезаписывания системных файлов

* ❌ **ЗАПРЕЩЕНО**: Хранить полные копии файлов интерфейса (`browser.xhtml`, `browser.css`, `preferences.xhtml`, `preferences.css`, `tokens-shared.css`, `tokens-platform.css`, `activity-stream.css`) из старых версий в каталоге `overlay/` и слепо копировать их поверх нового движка.
* ⚠️ **Почему**: Каждый релиз Firefox меняет структуру DOM, ID элементов, ссылки на файлы локализации Fluent (`.ftl`), системные CSS-переменные дизайн-системы. Копирование старого файла целиком ломает парсинг XUL/XHTML, лишает меню нужных обработчиков и приводит к пустым или поломанным меню.
* ✅ **ПРАВИЛО**: Базой ВСЕГДА служат файлы текущей распакованной версии движка (`test/squashfs-root/`). Изменения DeckyWolf вносятся исключительно как точечные вставки (патчи или аппенды уникальных блоков кода).

## 2. Контекстные меню и меню управления браузером (appMenu / «гамбургер»)

* **Что нельзя ломать**:
  - Контекстные меню вкладок (`#tabContextMenu`), веб-страницы (`#contentAreaContextMenu`), адресной строки и ссылок.
  - Главное меню управления браузером (`#appMenu-mainView`).
  - Все Fluent-ссылки локализации (`viewSource.ftl`, `browser/miniWindow.ftl` и др.).
* **Что разрешено добавлять в `browser.xhtml`**:
  1. Кнопку `#appMenu-torrent-button` (TorrentWolf) в список `#appMenu-mainView`.
  2. Панель диалога веб-приложений `<panel id="deckywolf-webapp-panel">` перед закрывающим тегом `</popupset>`.
  3. Кнопки на тулбаре (`#deckywolf-control-mode-button`, `#deckywolf-belylis-button`, `#deckywolf-webapp-button`) непосредственно перед `#nav-bar-overflow-button`.
  4. Скрытие заблокированных в LibreWolf пунктов ИИ в контекстном меню вкладок (`hidden="true"` на `#context_askChat` и `#context_aiSeparator`).
* **Критерий приёмки**:
  - Правый клик по вкладке показывает полноценное меню: «Перезагрузить», «Закрепить», «Выгрузить вкладку», «Закрыть вкладки справа» и т.д.
  - Правый клик по странице показывает: «Назад», «Вперёд», «Сохранить как», «Печать», «Просмотреть код» и т.д.
  - Меню «гамбургер» содержит все разделы без пустых пробелов.

## 3. Кнопки навигации (Назад, Вперёд, Обновить) и режим управления

* **Что нельзя ломать**:
  - Кнопки тулбара `#back-button`, `#forward-button`, `#reload-button`.
  - Вокруг них НЕ должно быть паразитных кругов, рамок или искажений.
* **Причина бага с «кругами»**:
  1. В старом `browser.css` содержались устаревшие глобальные правила GTK с `border-radius: var(--border-radius-circle)`.
  2. Бейджи контроллера (круги с буквами B, X, Y через `::after`) активируются ТОЛЬКО селектором `:root[deckywolf-controller-active]`.
  3. Если режим браузера по умолчанию установлен в `controller`, эти круги отображаются в обычном режиме рабочего стола.
* **ПРАВИЛО**:
  - По умолчанию режим управления в `librewolf.cfg` ОБЯЗАН быть:
    ```javascript
    defaultPref("deckywolf.controlMode", "keyboard");
    ```
  - В десктопном режиме DeckyWolf запускается как обычный браузер с мышью/трекпадом.
  - Переключение в режим контроллера происходит либо по клику на кнопку геймпада в тулбаре, либо автоматически в SteamOS Game Mode (Gamescope).

## 4. Отображение иконки AppImage на рабочем столе и в Dolphin

* **Что нельзя ломать**:
  - Файл `deckywolf.appimage` на рабочем столе Steam Deck и в файловом менеджере Dolphin ДОЛЖЕН иметь фирменную иконку DeckyWolf, а не дефолтную системную иконку шестерёнки AppImage (`application-vnd.appimage`).
* **Причина бага**:
  - Генератор миниатюр KDE Frameworks 6 (`/usr/lib/qt6/plugins/kf6/thumbcreator/appimagethumbnail.so`) читает файл `.DirIcon` из корня squashfs внутри AppImage напрямую через libsquashfuse.
  - Если `.DirIcon` является **символической ссылкой** (`ln -sf deckywolf.png .DirIcon`), thumbnailer не может разыменовать симлинк внутри контейнера и падает, в результате KDE присваивает файлу стандартную иконку типа MIME.
* **ПРАВИЛО**:
  - В `build.sh` файл `.DirIcon` ОБЯЗАН быть реальным файлом PNG:
    ```bash
    rm -f "$SQUASHFS_TARGET/.DirIcon" "$SQUASHFS_TARGET/deckywolf.png" "$SQUASHFS_TARGET/librewolf.png"
    cp -f "$OVERLAY_DIR/root/deckywolf.png" "$SQUASHFS_TARGET/deckywolf.png"
    cp -f "$OVERLAY_DIR/root/deckywolf.png" "$SQUASHFS_TARGET/.DirIcon"
    cp -f "$OVERLAY_DIR/root/deckywolf.png" "$SQUASHFS_TARGET/librewolf.png"
    ```
  - При обновлении на Steam Deck очищать кэш миниатюр: `rm -rf ~/.cache/thumbnails/*`.

## 5. Дизайн-система и токены (`toolkit_omni`)

* **Что нельзя ломать**:
  - Цвета меню, списков, инпутов, радиокнопок, скроллбаров.
* **ПРАВИЛО**:
  - В `tokens-shared.css` и `tokens-platform.css` переопределяется ТОЛЬКО акцентный цвет Decky Blue:
    - `tokens-shared.css`: `--color-violet-50: #1098fe;`
    - `tokens-platform.css`: `--color-accent-primary: light-dark(#1098fe, #38bdf8);`
  - Все остальные 1000+ переменных текущей версии движка остаются нетронутыми.

---

## 6. Стартовая страница (New Tab / about:home)

* **Что сохраняется**:
  - Фирменный тёмный радиальный градиент Decky Loader (`#06090f`, `#1098fe`).
  - Центрированное выравнивание логотипа и надписи DeckyWolf.
  - Плитка TorrentWolf с rich-иконкой на порту 8404.
* **ПРАВИЛО**:
  - Стили дописываются в конец актуальных `activity-stream.css` и `nova/activity-stream.css`.
